# KMZee Technology Website

🌐 **Live Site:** https://kmzeetech.netlify.app

A redesigned, bilingual website for KMZee Technology, targeting businesses in Saudi Arabia and India.

## Features
- English and Arabic language support
- Light and dark themes
- Responsive design
- Installable Progressive Web App (PWA)
- SEO optimization
- Offline support

## Getting Started

```bash
npm install
npm run build
npm start
```

Open http://localhost:3000 to view the website locally.


## Project Structure
- `app/` — Pages and styles
- `components/` — UI components
- `data/` — Website content
- `lib/` — SEO and site settings
- `public/` — Images and PWA assets
- `scripts/` — Build scripts
